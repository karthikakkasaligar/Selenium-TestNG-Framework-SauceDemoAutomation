# Selenium TestNG Framework - SauceDemo Automation

## Overview

This project is an automation testing framework developed for the SauceDemo application using Selenium WebDriver, Java, TestNG, and Maven. The framework follows the Page Object Model (POM) design pattern to improve maintainability, scalability, and reusability.

## Tech Stack

* Java
* Selenium WebDriver
* TestNG
* Maven
* Git & GitHub
* Page Object Model (POM)

## Framework Features

* Page Object Model Design Pattern
* Reusable Components
* Explicit Waits
* TestNG Assertions
* Data-Driven Approach
* Maven Dependency Management
* Git Version Control
* Detailed Test Execution Reports
* Cross-Browser Execution Support (Extendable)

## Project Structure

src/main/java

* Page Objects
* Reusable Components
* Global Data

src/test/java

* Test Cases
* Test Components

testng.xml

* Test Suite Execution

pom.xml

* Maven Dependencies and Build Management

## Test Scenarios Covered

### Login Validation

* Valid Login
* Invalid Username
* Invalid Password
* Empty Credentials Validation

### Product Validation

* Verify Product Names
* Verify Product Prices
* Verify Product Details

### Cart Validation

* Add Product to Cart
* Add Multiple Products to Cart
* Remove Product from Cart
* Verify Cart Item Count

### End-to-End Validation

* Login
* Product Selection
* Cart Validation
* Checkout Process
